# Strains compatible with a specimen's single-allele calls

Strains compatible with a specimen's single-allele calls

## Usage

``` r
multinomial_compatible_strains(i, D, model_obj, fallback)
```

## Arguments

- i:

  Specimen index

- D:

  Integer dictionary

- model_obj:

  Model object

- fallback:

  Strain index used when nothing matches

## Value

Integer vector of strain indices
