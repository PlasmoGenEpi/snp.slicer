# Log-likelihood for binomial model (vector version)

Log-likelihood for binomial model (vector version)

## Usage

``` r
binomial_loglikelihood_vector(propvec, yvec, rvec)
```

## Arguments

- propvec:

  Proportion vector

- yvec:

  Observed counts vector

- rvec:

  Total counts vector

## Value

Log-likelihood value
