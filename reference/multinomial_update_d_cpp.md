# Compiled dictionary update for the multinomial model

Gibbs step over alleles in ratio form; see
[`multinomial_update_d_r`](https://plasmogenepi.github.io/snp.slicer/reference/multinomial_update_d_r.md)
for the reference and `update_d_multinomial` in the C++ source for the
derivation.

## Usage

``` r
multinomial_update_d_cpp(state, model_obj)
```

## Arguments

- state:

  Current state

- model_obj:

  Model object

## Value

Updated state
