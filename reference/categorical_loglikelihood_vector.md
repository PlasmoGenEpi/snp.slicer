# Log-likelihood for categorical model (vector version)

Log-likelihood for categorical model (vector version)

## Usage

``` r
categorical_loglikelihood_vector(propvec, yvec, rvec = NULL)
```

## Arguments

- propvec:

  Proportion vector

- yvec:

  Observed categorical values

- rvec:

  Not used for categorical model (kept for interface consistency)

## Value

Log-likelihood value
